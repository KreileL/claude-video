# watch MCP v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a local inbox, long-video async jobs (no 15 min cap) and better pt-BR transcription to the watch MCP server, as image `watch-mcp:v2` / Desktop entry `watch-v2`, without touching v1 (`watch-mcp:latest`, entry `watch`).

**Architecture:** An always-on `watch-worker` compose service (same image, `python /app/worker.py`) processes a queue of job directories on the named volume `watch-mcp-jobs` (`/jobs`). The stdio server only creates `job.json` (state `queued`) and reads results; the worker owns every other write. Per job the worker downloads (URL, through netguard) or opens (inbox, by fd), extracts audio + a frame index (scene cuts + time grid, 512 px JPEG), deletes the video, transcribes in silence-aligned chunks persisted one by one (resume after restart), then deletes the audio. `watch_video(job_id, …)` serves index frames + transcript slice; no ffmpeg in the server for jobs.

**Tech Stack:** Python 3.12 stdlib, mcp 2.3.0, yt-dlp, ffmpeg 7.1, speaches 0.8.3 (existing `watch-mcp-whisper`), Docker Compose project `watch-mcp`.

**Spec:** the user's brief (conversation of 2026-10-18), summarized in NOTES-mcp.md § v2.

## Global Constraints

- Never rebuild/retag `watch-mcp:latest`; never edit the `watch` Desktop entry; `watch-whisper` service definition unchanged.
- Never touch containers outside project `watch-mcp`. Docker tasks one at a time; subagents do not run Docker.
- Tests: `.venv/Scripts/python.exe -m pytest -q`. Nothing in global Python.
- No `shell=True`. argv lists only. Messages to the user in Portuguese.
- Every v1 control stays (NOTES-mcp.md "Security controls").
- Inbox extensions: mp4, mkv, mov, webm, m4v, mp3, m4a, wav, ogg, opus. ffmpeg/ffprobe on local inputs: `-protocol_whitelist file`.
- Defaults: job max duration 4 h, URL download 4 GiB (netguard budget), job timeout 8 h, TTL 7 days, disk cap 20 GiB — all env-configurable.
- job_id = `secrets.token_hex(16)` (32 lowercase hex), validated by regex before any path use.
- No cookie/secret ever written under `/jobs`.

## Review Focus

1. An inbox file swapped for a symlink (or rewritten into a playlist) between validation and ffmpeg → must still read only the validated inode, forced demuxer (fd + `-f`).
2. Worker killed mid-download / mid-index → job restarts that stage; mid-transcription → done chunks kept.
3. Volume full / cap reached while jobs queued → cleanup never deletes queued/running jobs; running job fails with clear error.
4. Malformed `job.json` or foreign dir in `/jobs` → listed/served jobs skip it; never crash list_jobs.
5. Whisper restarted mid-job → chunk retried with backoff before the job fails.

### Task 1: `jobstore.py` — queue/cache on disk (Sonnet)

**Files:** Create `jobstore.py`, `tests/test_jobstore.py`

**Interfaces — Produces:**
- `JOBS_DIR: Path` (env `WATCH_JOBS_DIR`, default `/jobs`); `JOB_ID_RE = ^[0-9a-f]{32}$`; `STATES = ("queued","running","done","failed")`
- `class JobError(ValueError)`
- `new_job_id() -> str`
- `job_path(job_id: str, root: Path | None = None) -> Path` — raises `JobError("job_id inválido")` unless regex matches.
- `write_json_atomic(path: Path, data) -> None` (tmp file in same dir + `os.replace`); `read_json(path) -> dict | None` (None on missing/corrupt)
- `create_job(fields: dict, root=None) -> dict` — new id, dir mode 0o700, job.json with `id, state="queued", created, updated, progress=0.0, stage="na fila", error=None` + fields.
- `load_job(job_id, root=None) -> dict` — `JobError("trabalho não encontrado")` if absent.
- `update_job(job_id, root=None, **fields) -> dict` — sets `updated`.
- `list_jobs(root=None) -> list[dict]` — newest `created` first; skips symlinks, non-matching names, corrupt json.
- `find_cached(cache_key: str, root=None) -> dict | None` — newest job with that key in queued/running/done.
- `next_job(root=None) -> dict | None` — oldest `running` (resume) else oldest `queued`.
- `dir_size(path) -> int` (no symlink following)
- `cleanup(root=None, *, ttl_seconds: float, max_bytes: int, now: float | None = None) -> list[str]` — remove done/failed with `updated` older than TTL; then oldest-finished-first until total ≤ max_bytes; dirs with no valid job.json older than 1 h; never queued/running.

Tests: id format/uniqueness; traversal ids (`../x`, `A`*32, 31/33 chars) rejected; atomic write leaves no tmp; list ordering + skips corrupt/foreign/symlink; next_job prefers running; cleanup TTL, cap, never active, orphan dirs.

### Task 2: `inbox.py` — local inbox (Sonnet)

**Files:** Create `inbox.py`, `tests/test_inbox.py`

**Produces:**
- `INBOX_DIR` (env `WATCH_INBOX_DIR`, default `/inbox`); `ALLOWED_EXTS`; `FORMAT_DEMUXERS = {"mov,mp4,m4a,3gp,3g2,mj2": "mov", "matroska,webm": "matroska", "mp3": "mp3", "wav": "wav", "ogg": "ogg"}`
- `class InboxError(ValueError)` (Portuguese messages)
- `check_name(name: str) -> str` — rejects empty, > 255 chars, `/ \ :`, control/format chars, leading `.`, `..`, absolute, disallowed ext (case-insensitive).
- `resolve(name, root=None) -> Path` — check_name; `lstat` → symlink or non-regular rejected; parent must equal root.
- `list_inbox(root=None) -> list[dict]` — `{name, size_bytes, modified}` (ISO), allowed regular files only, sorted.
- `open_media(name, root=None) -> int` — `os.open(O_RDONLY|O_NOFOLLOW)` (POSIX), `fstat` regular; caller closes.
- `fd_path(fd: int) -> str` — `/proc/self/fd/{fd}` (POSIX).
- `probe(path: str, pass_fds=()) -> dict` — `ffprobe -v error -protocol_whitelist file -print_format json -show_format -show_streams <path>`; returns `{duration, demuxer, has_video, has_audio, width, height}`; `InboxError` when ffprobe fails, format not in FORMAT_DEMUXERS, no audio/video stream (attached pictures don't count as video), duration ≤ 0.

Tests (ffmpeg-synthesized): names table; symlink rejected (skip on Windows); m3u8 / ffconcat renamed `.mp4` rejected by probe; text file `.mp4` rejected; real mp4/mkv/mp3/wav accepted with right demuxer; mp3 with cover art → has_video False.

### Task 3: `textsearch.py` + `chunking.py` (Sonnet)

**Files:** Create `textsearch.py`, `chunking.py`, `tests/test_textsearch.py`, `tests/test_chunking.py`

**Produces:**
- `textsearch.normalize(text) -> str` — NFKD, drop combining marks, casefold, non-alphanumeric → space, collapse.
- `textsearch.search(segments: list[dict], query: str, limit: int = 20) -> tuple[list[dict], int]` — hits `{start, end, text, before, after}` + total; phrase match in a segment or spanning it and the next; if no phrase hit, all query words (≥ 2 chars) in one segment. `ValueError` on empty query.
- `chunking.parse_silences(stderr: str) -> list[tuple[float, float]]` (ffmpeg `silencedetect` output)
- `chunking.plan(duration: float, silences, target: float = 300.0, window: float = 30.0) -> list[tuple[float, float]]` — contiguous `(start, end)` covering `[0, duration]`; each cut at the silence midpoint nearest `k*target` within ±window, else at `k*target`; last chunk absorbs a remainder < target/2.
